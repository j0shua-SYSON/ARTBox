(100%)** in each of two native ARM64 macOS processes. All portable host checks,
native Linux comparisons and the integrated iOS 15 build pass. Physical checks
are waived as milestone gates; physical execution remains unverified.

The downloaded artifact matches its build manifest. All seven Mach-O images
(app, two M1 frameworks and four M2 frameworks) have iOS 15 load commands,
code-signature commands and no W+X segment permissions. The four original ELF
resources, signed payloads, complete notices and embedded manifest match the
tested inputs. CI verifies signatures with `codesign --verify --strict` and
empty entitlements. This is an ad-hoc transport IPA requiring ordinary
provisioning for installation; it does not establish device launch or lifecycle
behavior. The macOS executable and iOS console call the same diagnostic runner.

The pthread workload uses four joinable and two detached Bionic workers, each
performing 32 allocation/file iterations with mutex/condition synchronization,
errno/key isolation, inherited guest signal masks and destructor cleanup. A
native reaper joins actual thread termination before clear-TID and stack release.
Two standard ELF TLS templates serve main and six workers; initialization,
zero fill, alignment, persistent mutations and resolver register preservation
pass. Four libraries resolve versioned calls to 46 and run three constructors.

Twenty portable CTest contracts pass on Windows/MSVC, macOS/Clang and Linux/GCC.
Additional Python checks validate packaging, source adaptations and scoring.
Native Linux ARM64 runs original NDK ELF callers and original/adapted Bionic
syscall entries. Artifact comparisons verify shared source/object hashes, TLS,
versions, files, mappings, timeout and proc results. The proc Linux baseline
predates its virtual implementation. Opaque pthread structures are compiled
against each runtime's own headers; they are not shared across libc ABIs.

## Provenance and no-JIT costs

Bionic is pinned to Android `android-15.0.0_r1`, commit
`361ba86734fb2821a6adcfdf775db8abd04e0de0`, with 221 selected sources and two
compiler-rt members. NDK r28c (`28.2.13676358`, Clang 19.0.1) builds the guest
ELFs. Scudo, GWP-ASan and other selected dependencies are independently pinned
and licensed in [THIRD_PARTY.md](../../THIRD_PARTY.md). Artifact manifests retain
source archives, object and signed-layout hashes and notices.

Native wrappers are prepared and signed at build time. Runtime relocations
touch data only; guest mappings never gain execute permission. Controlled source
adaptations route Bionic syscalls and thread state through precompiled bridges.
ELF TLS uses a precompiled absolute-address TLSDESC resolver with Bionic's real
DTV, preserving Darwin's thread pointer. It currently saves full SIMD state
around the accessor; isolated TLS overhead has not been measured. This does
not support arbitrary prebuilt APK native libraries or other TLS access models.

## Failures resolved and remaining limits

The native Linux file oracle exposed use of generic rather than ARM64 open
flags; target-header assertions and the corrected mapping now pass unchanged
cases. Native thread cleanup needed a reaper to avoid releasing a stack while
the host pthread still used it. Full TLS integration exposed a leftover
fixture-loader TLS rejection, which was removed after template/relocation
validation was implemented. No failing acceptance check was disabled.

The runner is single-use and diagnostic; failed contracts or unexpected native
faults may terminate its process. The loader has no general dlopen growth,
preinit/finalization or unloading. Signal masks are state only: delivery,
alternate stacks and recoverable guest memory faults remain unsupported.
Proc command lines are immutable initial snapshots, without live argv changes.
Mutable directories, dup/fcntl and broader file, process and socket operations
remain gaps; unsupported syscalls are retained in native reports. Native file
I/O runs on POSIX hosts, with injected portable VFS tests on Windows.

## Three largest M3 risks

1. ART's source/dependency footprint and reproducible minimal build, including
   a trustworthy host DEX reference and class-library subset.
2. ART's managed ABI, stack walking, thread suspension and signal assumptions;
   interpreter-only execution must also avoid runtime executable mappings.
3. Ordinary iOS address-space and resident-memory limits. Scudo's roughly
   8.25 GiB virtual reservation and Mac RSS do not establish an iPhone budget.
