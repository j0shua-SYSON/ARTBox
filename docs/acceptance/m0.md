# M0 acceptance

The startup console and cross-platform Python automation pass CI at tag `m0`,
commit `0d2ba675e50744690d012b90f156122177a7f751`.
The project owner waived physical-device checks for all milestones. Physical-device execution
and lifecycle behavior remain unverified; no device pass is claimed.

- [PR #1](https://github.com/j0shua-SYSON/ARTBox/pull/1).
- [Host CI](https://github.com/j0shua-SYSON/ARTBox/actions/runs/34735009691):
  Windows/MSVC, macOS/Clang and Linux/GCC; two CTest tests and the Python
  configurable-path subprocess test pass on each host.
- [iOS CI](https://github.com/j0shua-SYSON/ARTBox/actions/runs/34735009733):
  arm64 iOS 15 device build, Xcode 16.4 (16F6), iOS SDK 18.5.
- Tested revision equals tag `m0`; working tree clean.
- IPA SHA-256: `7eaf6c41f0bf10adf14d43fe3dae4404c8b934af205a1c6329f9be666bc9ac1d`.
- IPA: 12,036 bytes; executable: 93,632 bytes.
- Downloaded artifact: `artifacts/m0-final/ios/ARTBox.ipa`. Its hash matches
  the CI manifest; bundle metadata and Mach-O commands both declare iOS 15.

CI verifies the arm64 device architecture, iOS minimum version, no W+X initial
segment permissions, portable startup symbol, valid ad-hoc transport signature,
and empty entitlements. The manifest explicitly records
`device_launch_verified: false`. Installation requires ordinary provisioning.

## Resolved build failures

The initial iOS integration exposed a CMake library-output mismatch from an
`xcodebuild` directory override and a missing explicit CoreGraphics link.
The final build keeps CMake's configured library paths and links CoreGraphics.
No test or compiler check was disabled. The Python tooling passes all three
host platforms and the device build without additional package installations.

## Next-milestone risks

1. Preserving ELF addressing inside signed, dyld-compatible Mach-O containers.
2. Android/Apple ABI differences, including reserved registers and TLS.
3. Bionic needs more than the first five syscalls. M1's libc-free NDK fixture
   does not establish dynamic Bionic or APK compatibility.
